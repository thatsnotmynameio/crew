## Planning Contract

### Key Technical Decisions

- KTD1. **`dupl` runs at a threshold of 100 tokens.** This is Codacy's `minTokenMatch`, so the bar does not move when ownership does. golangci-lint's default of 150 would let through clones Codacy catches today.
- KTD2. **`dupl` skips `_test.go` files, through an exclusion rule beside the existing `goconst` and `gochecknoglobals` ones.** Codacy skipped them for the same reason: table-driven tests repeat their case shape on purpose. Recorded fixtures need no rule, because `./...` never loads a `testdata` directory and `dupl` reads only Go. Measured on 2026-10-09 with v2.14.0, the test files hold 3 pairs, in `internal/config/config_global_test.go`, `internal/engine/ask_test.go` and `internal/fake/fake_test.go`; the rule makes them pass.
- KTD3. **Each duplicate is fixed when the two copies repeat a mechanism, and suppressed at the finding when they are parallel variants or data.** At 100 tokens with tests skipped, the root module has 4 pairs and `acceptance/` has none:

  | Pair | What repeats | Decision |
  | --- | --- | --- |
  | `internal/engine/function.go` `runFunction` and `runStepFunction` against `internal/engine/shell.go` `runShell` and `runStepShell` | Making the timeout context in the loop, registering its cancel, and the goroutine that runs and posts | Fix (U1) |
  | `internal/fake/tracker.go` `StatusBoard.ReportStatus` against `PullRequestBoard.ReportPullRequests` | Pop a scripted failure, create the map on first use, append by issue key | Fix (U2) |
  | `internal/crew/fact_action.go` `ShellEnded.decide` against `FunctionEnded.decide` | Two cases of the sealed fact family. Every type, spec and judge differs; only the shape is shared, as with `SessionEnded.decide` | Suppress |
  | `internal/ui/tui/styles.go` `darkPalette` against `lightPalette` | Two palette literals with different colours: data, not logic | Suppress |

  A suppression is `//nolint:dupl // <reason>` on each reported declaration of the pair, as `.golangci.yml`'s `nolintlint` requires, and as AGENTS.md asks for a genuine false positive.
- KTD6. **The threshold, the test exclusion and every suppression live in `.golangci.yml` and the code, read from the pull request's merged tree.** A pull request that changes them is judged by its own change (R8).

### Assumptions

- Sorting the four pairs into fix and suppress is this plan's judgement (KTD3). A reviewer may prefer to fix a suppressed pair. The bar is unchanged either way: `dupl` reports nothing.

### Sequencing

## Implementation Units

### U3. Turn on dupl at 100 tokens, skip tests, justify the two variant pairs

**Goal:** `.golangci.yml` runs `dupl` everywhere golangci-lint runs, and the root module and `acceptance/` report no finding.

**Requirements:** R4, R8. KTD1, KTD2, KTD3, KTD6.

**Dependencies:** U1, U2.

**Files:**
- `.golangci.yml`
- `internal/crew/fact_action.go`
- `internal/ui/tui/styles.go`
- `.codacy.yaml` and `.codacy/codacy.config.json`

**Approach:**
1. Remove `dupl` and its comment from `linters.disable`.
2. Add `linters.settings.dupl.threshold: 100`, with a one-line comment saying it matches the bar Codacy held (KTD1).
3. Add an exclusion rule for `dupl` on `_test\.go`, with the reason in a comment (KTD2).
4. Put `//nolint:dupl // <reason>` on `ShellEnded.decide` and `FunctionEnded.decide`, and on `darkPalette` and `lightPalette`. Each reason says why the pair is not a clone (KTD3).
5. In `.codacy.yaml`, fix the duplication comment that says golangci-lint's `dupl` is off: `dupl` now owns duplication in CI, and this block stays until Codacy leaves (#385). Then run `pnpm exec codacy-analysis update-config` and commit both files, as AGENTS.md requires.

**Patterns to follow:** the `_test\.go` exclusion rules for `goconst` and `gochecknoglobals` in `.golangci.yml`, and each `disable` entry's reason comment.

**Test scenarios:**
- Test expectation: none, because this is configuration. Verification below proves it.

**Verification:**
- golangci-lint v2.14.0 at the root and in `acceptance/` reports nothing. `nolintlint` reports no unused `nolint:dupl`.
- With the threshold in place, removing one of the four suppressions makes `dupl` report that pair again. Checked by hand, then restored.
